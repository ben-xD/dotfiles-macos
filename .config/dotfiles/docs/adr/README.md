# Architecture Decision Records

Records of non-obvious decisions about how this machine's config is set up: the
"why" behind choices that aren't self-evident from `flake.nix` / `home.nix`.

Format: one file per decision, `NNNN-title.md`, numbered sequentially. Loosely
follows [MADR](https://adr.github.io/madr/). Status is one of Proposed / Accepted /
Superseded.

- [0001](0001-forgejo-token-secret-storage.md) — FORGEJO_TOKEN storage for the tlduck npm registry
